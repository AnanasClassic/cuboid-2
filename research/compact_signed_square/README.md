# Compact signed-square completion model

This directory gives an exact, low-memory model of the complete signed-square
`2+3` locus.  It closes every denominator exception in its reverse lift.  The
admissible rational points are now excluded by the reciprocal quotient,
elliptic transport, and genus-two square-abscissa theorem described below;
consequently C010 and Sharipov's second cuboid conjecture are proved.

The certificate is generated by `compact_signed_square.py`; its canonical
output is `compact_signed_square.json`.

## The substitution

Let

```text
R1(s,a,b) = R0(s,a,b) = 0
```

be the exact remainder equations for a monic quadratic factor
`x^2+a*x+b` of `P_s(x)`.  Signed-square descent proves that a genuine factor
has `b` equal to a rational square or the negative of one.  Since an
admissible cuboid parameter is itself a positive rational square, write

```text
s = z^2,
b = epsilon*z^4*k^2,
a = z^2*k*y,
epsilon in {+1,-1}.
```

This is lossless for finite admissible data: if `b=epsilon*c^2`, take
`k=c/z^2` and `y=a/(z^2*k)`.  Conversely the displayed formulas recover
rational `s,a,b` from rational `z,k,y`.

After removing boundary monomials, put

```text
F1_epsilon = R1(z^2,z^2*k*y,epsilon*z^4*k^2)/z^4,
F0_epsilon = R0(z^2,z^2*k*y,epsilon*z^4*k^2)/z^6.
```

They are polynomials with respectively 27 and 19 terms and degrees four and
three in `y`.  Exact elimination gives

```text
Res_y(F1_epsilon,F0_epsilon)
  = -epsilon*z^20*k^12*Q_epsilon(z,k),
```

where `Q_epsilon` is irreducible over `QQ`, has bidegree `(16,20)`, and has
only 71 terms.  The two signs are quadratic twists:

```text
Q_-(z,k) = -Q_+(z,i*k).
```

Thus every admissible factor maps to `Q_epsilon(z,k)=0`.  The next section
proves the converse without leaving an exceptional rational denominator
branch.

## Exact inverse and its exceptional locus

The penultimate subresultant in `y` is `L1*y+L0`.  Define

```text
ell_epsilon =
    k^10*z^2 + 6*k^6*z^4 - k^6*z^2 - 2*k^6
    + epsilon*(2*k^4*z^4 + k^4*z^2 - 6*k^4 - z^2),

L1 = -z^2*ell_epsilon,

M = k^6*(z^8 + 10*z^6 + 4*z^4 - 14*z^2 + 1)
    - k^2*(z^8 - 14*z^6 + 4*z^4 + 10*z^2 + 1),

D = 2*k^8*z^6 + k^8*z^4 - 6*k^8*z^2
    + 6*z^6 - z^4 - 2*z^2,

L0 = k*(epsilon*M-D).
```

On `L1 != 0`, set

```text
y = -L0/L1.
```

The certificate verifies by exact multivariate division that

```text
Q_epsilon divides L1^4*F1_epsilon(z,k,-L0/L1),
Q_epsilon divides L1^3*F0_epsilon(z,k,-L0/L1).
```

It remains to prove that `L1` cannot vanish at an admissible rational point.
The exact factorization, multiplied back in the script, is

```text
Res_k(Q_epsilon,ell_epsilon)
 = 2^20*z^24*(z-1)^12*(z+1)^12
   *(z^2-z+1)^4*(z^2+z+1)^4*(z^2+1)^12*Phi32(z)^4,
```

where

```text
Phi32(z) =
 z^32 - 77*z^30 - 1725*z^28 + 125174*z^26 + 6766*z^24
 - 1187796*z^22 + 1420733*z^20 + 1862827*z^18
 - 4451294*z^16 + 1862827*z^14 + 1420733*z^12
 - 1187796*z^10 + 6766*z^8 + 125174*z^6
 - 1725*z^4 - 77*z^2 + 1.
```

The three quadratic factors have discriminants `-3,-3,-4`.  The last
factor is monic with constant term one, so a rational root could only be
`+1` or `-1`; both values give `512`.  Therefore a rational common zero of
`Q_epsilon` and `ell_epsilon` has

```text
z in {-1,0,1}.
```

These are respectively the `s=1`, `s=0`, and `s=1` boundaries.  None is
admissible.

We have therefore proved the following exact equivalence.

> For either sign `epsilon`, finite admissible rational signed-square
> quadratic factors are equivalent to rational points
> `Q_epsilon(z,k)=0` with `z>0`, `z!=1`, and `k!=0`.  The inverse is the
> displayed `y=-L0/L1`, followed by
> `s=z^2`, `b=epsilon*z^4*k^2`, `a=z^2*k*y`.

This is stronger than a one-way resultant obstruction.  By itself it is not
a rational-point classification: the normalization is the existing full
signed-square cover of genus 33.  The next quotient supplies the completed
classification.

## Completed reciprocal descent

The directory `reciprocal_quotient/` derives the common irreducible 29-term
curve `C8(U,V)=0` for both physical signs.  It verifies the negative-branch
coordinate change directly, including its omitted `r=0` fibre, rather than
inferring it from a sign label.  The functions

```text
UV, 1-UV
```

are required nonzero squares in both signs.

`../arithmetic_geometry/low_degree_transport.py` gives exact maps in both
directions between the admissible normalization of `C8` and

```text
E1: y^2=x^3-5*x+4.
```

The inverse is certified by a linear subresultant and exact
multiplication-back; every source, inverse, and projective denominator fibre
is classified.  The transported product character descends to the genus-two
curve

```text
R^2=4*a^5-8*a^2+5*a
```

with `a` a rational square.  Exact 2-descent, an index-independent `7/23`
Mordell--Weil sieve, and a `p=7` Coleman bound show that its only such points
are `infinity,(0,0),(1,+/-1)`.  The direct lift table excludes every one.
See `../arithmetic_geometry/product_genus2_square_abscissa.md` and
`../../notes/quadratic_cubic_completion.md`.

## Minimum-width and monomial-symmetry audit

Before the square substitutions, eliminate `a` and put
`b=epsilon*d`.  The Newton polygon in `(s,d)` has vertices

```text
(0,9),(2,7),(10,3),(16,1),(20,0),
(20,1),(18,3),(10,7),(4,9),(0,10).
```

Its lattice width is exactly eight, attained in direction `(1,2)`.  Indeed,
width below eight would give `|beta|<8` from the two vertical unit edges and
`|20*alpha-10*beta|<8` from `(20,0)-(0,10)`.  Hence
`beta=2*alpha`; primitivity leaves only `+/- (1,2)`, whose width is eight.
The substitution

```text
d=s^2*v
```

realizes this minimum as an irreducible bidegree-`(8,10)`, 71-term model.

An exhaustive affine-lattice automorphism check of the Newton support finds
four support symmetries.  Coefficient compatibility, including possible
torus scalings, leaves only the identity and simultaneous reciprocity.  For
each of the other two, the coefficient ratios on the exponent
parallelogram

```text
(12,4)+(2,8) = (4,9)+(10,3)
```

fail multiplicativity by exactly `-64/85`.  Hence no additional
Laurent-monomial `V4` or `D4` action is hidden in this compact projection.
The support points `(20,1),(20,0),(19,2)` have difference determinant one,
so the exponent lattice is saturated and no extra root-of-unity scalings are
missed.
This statement is limited to monomial coordinate changes; it is not a claim
about the full abstract automorphism group.

## Genus-four ambient Möbius no-go

The script also proves a separate exact no-go for the displayed genus-four
model

```text
G(X,A)=X^8*H(X+1/X,A).
```

The factorization of `Disc_A(H)` is

```text
C*(q+2)^20*(q-2)^27*(3*q+10)^4
 *f2(q)^12*f3(q)^3*f15(q)^2,
```

with pairwise-coprime factors of degrees `1,1,1,2,3,15`.  On the binary
`X`-line the discriminant divisor therefore has unique multiplicity strata

```text
X=1: 54,   X=-1: 40,   {X=0,X=infinity}: 30.
```

Any rational Möbius transformation of `X` induced by an ambient
`PGL2 x PGL2` automorphism must fix `+/-1` and preserve `{0,infinity}`.
It is consequently either `X` or `1/X`.  Both fix the fibers

```text
G(-1,A)=2^16*(A-2)^10,
G(1,A)=2^27*A^3*(A-6)*(A^2-12*A+4)^3.
```

The transformation of `A` must fix `2`, the unique multiplicity-one root
`6`, and the only rational multiplicity-three root `0`; hence it is the
identity.  The only such ambient automorphisms are therefore the identity
and the already-known `X -> 1/X` involution.

This does not rule out a nonlinear/non-ambient automorphism or a Prym
splitting not induced by an automorphism.

## Reproduction

From the repository root:

```bash
python research/compact_signed_square/compact_signed_square.py \
  --output /tmp/compact_signed_square.json
diff -u research/compact_signed_square/compact_signed_square.json \
  /tmp/compact_signed_square.json
pytest -q tests/test_compact_signed_square.py
```

The complete generator takes only seconds with SymPy 1.14 and does not use
Sage, Singular, PARI, or high-memory normalization.
