# Simultaneous-reciprocal quotient

This directory contains a low-resource exact quotient of the positive
71-term compact signed-square model.  It is a reduction, not a rational-point
classification.

Put `S=z^2` and `K=k^2`.  The compact equation is invariant under the
simultaneous reciprocal involution `(S,K) -> (1/S,1/K)`.  The Cayley
coordinates

```
x=(S-1)/(S+1),   y=(K-1)/(K+1)
```

turn the involution into `(x,y) -> (-x,-y)`.  Its fixed field is generated by

```
U=x/y,   V=x*y.
```

`derive.py` proves, over `QQ`, that the quotient is the irreducible 29-term
curve `C8(U,V)=0` of bidegree `(6,6)` and total degree `8`.  It also verifies
the exact square-character identities

```
UV=x^2,                 1-UV=4S/(S+1)^2,
1-V/U=4K/(K+1)^2,       1-U/V=-4K/(K-1)^2.
```

The first two are common to both signed-square branches.  In the natural
coordinates of each source branch, the third positive character is `1-V/U`
and the third negative character is `1-U/V`.

The negative branch is checked directly, not inferred only from the character
algebra.  Its radial coordinates obey

```
r_plus=1/(X*r_minus).
```

Consequently its natural quotient equation is `C8(V_minus,U_minus)=0`, and a
coordinate swap identifies it with the displayed `C8`.  The potentially lost
fibre `r_minus=0` is
`F_minus(X,0)=X^2+34X-31`; its discriminant is `2^8*5`, so it has no
rational point.

The certificate evaluates the source equation at every denominator-zero
chart.  For physical `S>0`, `S!=1`, the only possible losses are boundary
points.  In particular, `K=-1` leaves a monic constant-one quartic whose only
possible rational roots are `+/-1`, and neither is a root.

Regenerate the certificate with:

```
python -m research.compact_signed_square.reciprocal_quotient.derive
```

This runs only exact SymPy computations and needs no normalization package or
large-memory machine.
