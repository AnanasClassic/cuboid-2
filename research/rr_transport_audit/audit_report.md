# Independent audit of the Singular RR-to-cubic transport

Date: 2026-08-05

Scope:

- `research/arithmetic_geometry/e_model_singular_rr_cubic.py`
- `research/arithmetic_geometry/e_model_sage_from_singular_cubic.py`
- the generated fast input and its workflow commands

This audit is static because the available local image has neither Singular
nor Sage.  The published GitHub run `30989105910` and its retry failed before
any step was allocated (`steps=null`, no log blob), so those failures contain
no evidence about either script.

## Result

No Singular or Sage API syntax error was found in the prepared route.  The
route is suitable for an exact CI execution.  A successful run certifies a
dense-open birational transport, not a complete classification of the
exceptional closed points.

Two deliberately stronger downstream guards are recommended:

1. Require `len(matches) == 1`, and specifically the expected candidate, in
   any job that starts the Mordell--Weil sieve.  The current transport script
   may legitimately certify a Weierstrass model with
   `candidate_exact_match=null`; that is not enough to import the separately
   certified Mordell--Weil basis of `544.c_E1`.  The prepared
   `research/mw_square_sieve/sage_mw_character_sieve.py` already enforces
   `candidate_exact_match == "544.c_E1"` and constructs the exact
   `source_curve.isomorphism_to(candidate)` before transporting the basis.
2. Split and classify the saturated source base locus, inverse base locus,
   and `inverseMap[3]=0` divisor before claiming a global rational-point
   bijection.  The present script correctly retains these ideals and labels
   the compositions as dense-open identities.

Neither recommendation is a blocker for the RR-to-Weierstrass certificate
itself.

## Singular API audit

The audit used the exact upstream sources at Singular commit
`f8e2789a17d3566f0ba24ff39046c81f5bd5f617`.

- `RiemannRochBN(C,I,J)` returns `list(IH,F)`, where `IH` is the ideal of
  common-degree numerators and `F` is the common denominator.  Therefore
  `RR3[1]`, `RR3[2]`, and `size(RR3[1])` are used with the correct types.
- For a singular plane model the procedure explicitly computes the
  Gorenstein adjoint ideal.  At the independently checked smooth point `P`,
  the ordinary powers `P^2` and `P^3` represent the effective divisors `2P`
  and `3P` in the quotient curve ring.
- Dropping the common denominator in the projective coordinates is valid:
  `[G1/F:G2/F:G3/F]=[G1:G2:G3]` on the dense open where the functions are
  defined.  The source base locus is retained separately.
- `invertBirMap(phi,C)` returns a ring containing the ideals `J` and `psi`.
  The `fetch` calls into the stable `(X,Y,W)` ring preserve generator order.
- A declaration `map f = SourceRing, images` in the current target ring has
  the orientation used by both `fromPlane` and `fromCubic`.
- `sat(I,maxideal(1))` returns an ideal.  In three homogeneous variables a
  projectively finite locus has coordinate-ring dimension at most one, so
  the three `dim(...) > 1` guards have the correct threshold.
- The three cross-minors are the correct equations for equality of
  projective triples.  Reducing them modulo the source and target ideals,
  together with the nonzero-coordinate guards, certifies the two rational
  compositions on dense opens.
- `system("--random",1)`, `system("--version")`, `export(a,b)`, and
  `fetch(R,obj)` agree with the upstream Singular test suite/library syntax.

## Sage API audit

The audit used the current Sage constructor and Weierstrass-transform source
and documentation.

- `Curve(cubic, P2)` is the documented `Curve(F,A=None)` argument order.
- `EllipticCurve_from_cubic(cubic, P=None, morphism=True)` is valid.  With
  `P=None`, Sage computes the Hessian intersection and uses a rational flex.
  The complete `|3P|` embedding has a rational flex, so requiring both returned
  maps to have degree-one defining polynomials is the appropriate guard.
- `.codomain()`, `.inverse()`, and `.defining_polynomials()` are the correct
  APIs for the returned `WeierstrassTransformationWithInverse`.
- Substituting the defining polynomials in both directions and reducing the
  three projective cross-minors modulo the cubic/Weierstrass ideals is a valid
  independent exact check.  The transformation's `post_rescaling()` is not
  needed for vanishing or for projective coordinates; it only normalizes the
  transformed equation by a nonzero scalar.
- `Curve(cubic).is_singular()` detects geometric singularities: a singular
  point over the algebraic closure makes the Jacobian ideal proper over the
  base field as well.
- `E.is_isomorphic(candidate)` and `E.isomorphism_to(candidate)` are the
  exact APIs needed to identify and then transport the separately certified
  Mordell--Weil basis.

## CI commands

The workflow command sequence is syntactically correct for the pinned Sage
container:

```bash
python3 research/arithmetic_geometry/e_model_singular_rr_cubic.py \
  --output certificates/e_model_singular_rr_cubic.sing \
  --metadata certificates/e_model_singular_rr_cubic_input.json
sage -sh -c \
  'Singular --random=1 -q certificates/e_model_singular_rr_cubic.sing' \
  2>&1 | tee certificates/e_model_singular_rr_cubic.txt
sage -python research/arithmetic_geometry/e_model_sage_from_singular_cubic.py \
  --transcript certificates/e_model_singular_rr_cubic.txt \
  --output certificates/e_model_singular_cubic_certificate.json
```

`set -o pipefail` and the final `grep` in the workflow correctly prevent a
partial Singular transcript from being accepted.
