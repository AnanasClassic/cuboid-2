## 0. Принципы

1. **Один маршрут — Lean-маршрут.** Статья доказывает ровно то, что доказано в
   `sharipov_second_cuboid_conjecture`, тем же путём. Никаких Schaefer–Stoll,
   Chabauty на D₊, Mordell–Weil-сит при 7/23, хэшей arXiv-архивов.
   Старые черновики `main/clean/clean2/clean3.tex` уходят в `paper/archive/`.
2. **Три сорта утверждений, три способа изложения.**
   - (A) Обычная математика (теория чисел, эллиптические кривые, вещественный
     анализ) — полное доказательство в тексте, со ссылками на учебники.
   - (B) Полиномиальные тождества, проверенные `ring`/`field_simp` — формула
     приводится только если она короткая (≤ ~15 членов) и нужна читателю
     для понимания; всё крупнее — одна фраза «явные многочлены A, B
     степени 12, 65 членов, файл `QuotientInverse.lean`» и ничего больше.
     Статья не печатает данные, она их описывает.
   - (C) Конечные перечисления (`decide`/`native_decide`) — одна фраза с
     точным описанием перебираемого множества и результатом (например,
     «перебор 48 пар (n,d) ∈ F₇² \ {0} показывает P6Hom(n,d) ≠ 0»).
     Таблицы не печатаются, кроме одной сводной (22 λ-адические строки).
   Целевой объём: **12–15 страниц основного текста**, плюс 2 страницы
   приложения (таблица имён Lean и сводка сертификатов).
3. **Каждой теореме — имя Lean-теоремы** (в скобках после номера или в
   маргиналии). В конце — таблица соответствия.
4. **Trust model отдельным параграфом**: Lean 4.33.0 + mathlib
   `db584cd…` + `native_decide` (только в ветке 2+3, в файлах Gaussian*,
   QuotientInverse, TransportExceptions); ветви 1+4 и 5+5 без `native_decide`.
5. **Библиография обязательна**: Sharipov arXiv:1108.5348, 1201.1229;
   Asiryan 2601.04240 (5+5), 2601.04241 (1+4, зависит от Magma);
   Asiryan–Rathbun 2601.07899 (2+3, только вычислительные свидетельства);
   Capell (1897, критерий для P(X²)); Silverman AEC (редукция, формальная
   группа, 2-изогенный спуск); mathlib (Fermat `not_fermat_42`,
   `AddCommGroup.fg_of_descent'`).
6. **Где статья короче Lean.** Lean доказывает с нуля: гомоморфность редукции
   mod 37, отсутствие кручения в формальной группе, конечную порождённость
   через наивную высоту. В статье эти места цитируются из Silverman
   (VII.2.1, IV.6.1/VII.3.1, VIII.3–4) с замечанием «в Lean доказано
   самостоятельно». Это законно: цитируемые теоремы стандартны.

### Гл. 5. The quadratic factor, II: rational points on r² = 4u⁸ − 8u² + 5 (4 стр.)
Это единственная глава с настоящей математикой, ей и отдаём место.
Стандартные факты (Морделл–Вейль, редукция, формальная группа) —
цитатами из Silverman, без доказательств.
Источники: `lean_route/03_gaussian_descent.md`, `04_gaussian_local_37.md`.
Theorem 5.0: точки октики над ℚ — ровно (±1, ±1)
(`octicRationalPointsClassified`).
- 5.1 Разложение нормы: 4u⁸−8u²+5 = N(q(u)), q(u) = (2u⁴−1) + i(2u²−2).
  Пифагорова лемма: u = m/n ⇒ либо q(u) = □ в ℚ(i) (n нечётно), либо
  −i·q(u) = □ (n чётно). Накрытия C₀: v² = q(u), C₁: w² = −i q(u); отображения
  C₀ → E₀: (2u², 2uv), C₁ → E₁: (−2iu², −2iuw), где
  E₀: y² = x³ + 2i x² − (2+4i)x, E₁: y² = x³ + 2x² + (2+4i)x.
  C₁(ℚ) = ∅ будет следовать из E₁(ℚ(i)) = {O, (0,0)} (образ (0,0) ⇒ u = 0 ⇒
  N(w)² = 5).
- 5.2 2-изогенный спуск над ℤ[i] (PID, единицы mod квадраты {1, i}).
  λ = 1+i, π = 1+2i, ρ = 1+4i; B₀ = iλ²π, B₁ = −iλ²π, A²−4B = ∓λ⁴ρ.
  Двойственные кривые E₀': X³−4iX²+(4+16i)X, E₁': X³−4X²−(4+16i)X.
  Отображения φ, φ̂ и Куммера α, α'. Носитель: 8 классов на кривую.
  λ-адические препятствия: однородные пространства W² = dU⁴ + AU²V² + eV⁴,
  перебор mod 4/8/16/32 — 22 строки, таблица в Приложение B (с тройками
